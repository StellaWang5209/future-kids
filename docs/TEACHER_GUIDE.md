# 教师指南 · Teacher Guide

**未来小孩 Future Kids — 链上数字文明教育平台**

> 本指南帮助教师 / 家长 / 社区志愿者在 40–60 分钟内组织一次完整的
> 「未来星球」课程。无需任何编程或区块链背景。

---

## 一、这套平台教什么？

五个世界，一条成长线：**信息如何被信任地记录 → 货币如何去中心化 →
安全如何由成本保证 → 安全如何由诚信保证 → 规则如何由代码执行（智能合约）**。

| 章节 | 世界 | 核心概念 | 学生产出 |
|---|---|---|---|
| 1 | 区块链世界 · 魔法记录本 | 区块、哈希链、去中心化账本 | 徽章「区块链探险家」 |
| 2 | 比特币世界 · 星星矿场 | 2100 万上限、减半、无国界网络 | 徽章「比特币先锋」 |
| 3 | PoW 世界 · 算力竞技场 | 工作量证明、挖矿竞速、能源代价 | 徽章「PoW 建造者」 |
| 4 | PoS 世界 · 守护者城堡 | 权益证明、质押、罚没（Slash） | 徽章「PoS 守护者」 |
| 5 | 以太坊世界 · 智能合约工坊 | 智能合约、自动售货机比喻、规则不可篡改、DApp | 徽章「以太坊建造者」 |

**明确的教学立场**：本平台不涉及任何投资、炒币或代币内容。
所有徽章为 Soulbound（不可转让、不可买卖），界面语言是「成长记录」而非「资产」。

## 二、课前准备（10 分钟）

1. **设备**：任意现代浏览器（教室电脑 / 平台 / 机房均可）。**不需要钱包、不需要安装、不需要账号。**
2. **网络**：可访问本平台即可。若教室无法联网，见第六节「离线运行」。
3. **隐私说明（请向家长转达）**：
   - 平台只让孩子起一个**化名**（如「星星骑士」），链上与本地都不收集姓名、生日、学校、照片。
   - Demo 模式下所有进度只保存在本机浏览器里。
4. 可选打印：每章的「知识钥匙」贴纸模板（见第五节答案钥匙）。

## 三、课堂流程（以 50 分钟为例）

| 时间 | 环节 | 要点 |
|---|---|---|
| 0–5 min | 「创造你的数字身份」 | 强调化名与隐私：「在网上，你可以只做自己想成为的样子。」 |
| 5–15 min | 第 1 章：搭块成链游戏 | 让学生亲手把区块连起来，再**篡改一个旧块**，观察整条链「断掉」——这是全课程最重要的一个瞬间。 |
| 15–22 min | 第 2 章：比特币配对 + 挖矿故事 | 讨论：为什么「写死在代码里的规则」比「承诺」更可靠？ |
| 22–32 min | 第 3 章：挖矿竞速 | 两人一组，一人当矿工一人当对手，体会「算力竞赛」与能源话题。 |
| 32–37 min | 第 4 章：质押与诚实抉择 | 每轮选「诚实 / 作弊」，让学生自己发现：作弊会被罚没，诚实最划算。 |
| 37–44 min | 第 5 章：搭建智能合约 | 按顺序搭出合约积木、点击「部署」，再用「自动售货机」现场试：不投币会被回滚、改价格会被拒绝 —— 规则由代码守护。 |
| 44–50 min | 成长地图复盘 | 打开「我的未来成长记录」：等级、徽章墙、时间线。请每位学生说一个「今天学到的词」。 |

**答题设计说明**：所有问答题答错可以重选，全对才继续 —— 这是刻意为之的
「学习而非考试」设计。请鼓励讨论，不要计时排名。

## 四、链上记录（完全可选）

Demo 模式已覆盖全部教学价值。如果学校希望让学生拥有**永久、可公开验证**的学习证明：

1. 监护人安装任意以太坊钱包（如 MetaMask），切换到 **Sepolia 测试网**（无真实资金）。
2. 在页面右上角连接钱包，完成章节后点击「将学习证明写入链上」。
3. 每份证明与徽章可在 Sepolia Etherscan 上查看，**且不包含任何个人信息**（只有地址 + 化名）。
4. 费用：Sepolia 是测试网，Gas 为零成本；主网部署属于未来规划，届时将公布资助方案，确保任何孩子都不因费用被排除。

## 五、答案钥匙（知识钥匙）

每章通关后展示的「知识钥匙」即链上证明的原文（合约保存其哈希）：

| 章节 | 知识钥匙 |
|---|---|
| 1 | `trust`（信任） |
| 2 | `2100万` |
| 3 | `proof-of-work` |
| 4 | `proof-of-stake` |
| 5 | `smart-contract`（智能合约） |

> 设计理念：**答案本身就是课程内容**。孩子把「学的那个词」亲手写进链上，
> 任何人都能验证「这个孩子学过这一课」，而无需知道这个孩子是谁。

## 六、离线 / 低带宽运行

```bash
# 在任何一台电脑上（需 Node.js ≥ 20，一次性）：
git clone <本仓库> && cd future-kids/frontend
npm install && npm run dev
# 教室局域网内所有设备访问 http://<教师机IP>:3000
```

链上功能在离线环境中自动降级为 Demo 模式，不影响教学。

## 七、常见问题

**Q：孩子会接触到钱吗？**
不会。测试网无真实资金；合约层面徽章不可转让；界面无任何价格、余额、交易功能。

**Q：换一台电脑，进度会丢吗？**
Demo 模式的进度保存在浏览器本地。如需跨设备保留，请在有监护人钱包的情况下使用链上模式。

**Q：可以删除孩子的数据吗？**
Demo 模式：点击地图页「重新开始」即可完全清除。
链上模式：这正是区块链的本质 —— 已上链的记录无法删除，因此我们从一开始就不上传任何个人信息。
